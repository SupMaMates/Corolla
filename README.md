## Start here

1. **[Install the panel](docs/INSTALL.md)** — download and verify the standalone kit, then create your administrator.
2. **[Sign in](docs/FIRST-USE.md#first-login)** — explicitly start the panel and open your chosen address.
3. **[Add your first channel](docs/FIRST-USE.md#add-your-first-channel)** — add content and subscribers, then start playback when ready.

## Requirements

A clean **Ubuntu 24.04 amd64** server with root access. Reference setup: **2 vCPU,
4 GiB RAM and 8 GiB free disk**. See the [full prerequisites](docs/INSTALL.md#before-you-start).

This prerelease is for controlled testing. **HTTP is unencrypted.** Read the
[release limits](docs/RELEASE.md) before installing; long-running operation remains unverified.
